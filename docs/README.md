# Blueberry documentation

This directory separates implementation planning from forensic reference
material used to understand the original application's high-level behavior.

## Project planning

- [Implementation plan](implementation-plan.md) — architecture, milestones,
  security requirements, data model, testing, and acceptance criteria.

## Reference material

- [Forensic analysis](forensic-analysis/README.md) — static findings about the
  installed Strawberry application. This material is evidence, not rebuild
  source code.

Keep new architecture notes, security documentation, and decision records in
this directory as the implementation grows. Keep application code outside
`docs/`, following the workspace layout in the implementation plan.
